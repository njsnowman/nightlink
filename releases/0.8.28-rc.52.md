# NightLink 0.8.28-rc.52 local candidate

Tracks [#213](https://github.com/njsnowman/nightlink/issues/213) and the [changelog](../CHANGELOG.md). Previous candidate: [rc.51](0.8.28-rc.51.md).

Owner request on 2026-11-19: make chat text and the hop count easier to read on the terminal chat screen (MRC). Presentation only; no radio, storage or delivery changes.

- Received messages: hop count and SNR are on the nick line, in one button (`mrc-delivery mrc-meta`, accessible name "View message path on map: …") that opens the message path. The separate `└─` line is no longer drawn for received messages. Own messages keep their delivery line.
- Hop badge colour by distance: direct green, 1-2 hops cyan, 3-4 yellow, 5+ magenta, black text on each (contrast at least 6.7:1). SNR colour: ≥ 5 dB green, 0-5 yellow, < 0 red, with a bar glyph. The values are always written out.
- Messages have 12 px more space above them, a line length capped at 88 characters, and a 2 px left rule: received bright blue, own grey, mentions yellow.

## Validation

The unit suite passed 531 tests. Browser checks passed for the terminal interface (updated: received lines now read `time <nick> [hops] SNR … message`; the test checks the tags share the nick line, their classes and accessible name, and that no separate delivery row is drawn for a received message), Terminal replies, terminal windows, reactions, message paths and delivery details. The accessibility audit passed 146 screens.
