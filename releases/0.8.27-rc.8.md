# Nightlink 0.8.27-rc.8 local candidate

Tracking issue: [#128](https://github.com/njsnowman/nightlink/issues/128)

## Scope

Adds a repo-local Codex MCP plugin and a local, read-only status bridge from Nightlink’s RF Propagation monitor. The bridge exports connection and monitor status, aggregate baseline and packet-rate metrics, the latest 50 sanitized receive observations, generic alert/lifecycle events and freshness. It does not expose messages, contact/station identifiers, exact location, radio configuration or secrets. It does not send radio commands or enable RX logging.
