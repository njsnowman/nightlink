# Nightlink 0.8.6 release record

Tracking: https://github.com/njsnowman/nightlink/issues/7
Status: validation complete; publication pending.

## Scope

Merged PR #6, tracked in #5: persistent channel and DM unread counts, remembered reading positions and new-message dividers, channel mute controls, independent DM/mention sound preferences, and conversation notification actions.

## Validation — 2026-10-15

- Full Node suite: 54 passed on final versioned source. Command: node --test bluetooth.test.cjs radio.test.cjs routes.test.cjs recovery.test.cjs delivery.test.cjs attention.test.cjs.
- node smoke.test.cjs: passed simulated GATT send, ACK, reconnect, retained history, contacts, mentions, DMs, compact layouts and maps.
- node attention.browser.test.cjs: passed unread persistence, reading positions across updates/reload, mute persistence, independent sounds, notification navigation, silent catchup and focused floating-DM reading.
- Packaged Windows build: passed app version 0.8.6, footer, unread/mute controls, native read bridge and sound settings. Prior feature validation includes native DM divider and focused reading-position IPC; release runtime changes only version identifiers.

## Limitations

Radio messages and browser notifications were simulated. No new physical-radio or Windows notification-center delivery validation is claimed. Browser audio may require interaction. Preferences are local to each application/browser profile. Existing 0.8.5 physical Bluetooth evidence is historical.
