## Changes

Overview Live mesh defaults to CoreScope on startup and each Overview entry, independently of the saved Network source. A temporary Radio map choice on Overview does not overwrite Network preference. CoreScope service/offline failure still switches to Radio map; returning to Overview retries CoreScope. Existing compact map-collapse behavior remains.

## Validation

- corescope-fallback.browser.test.cjs passed saved-radio startup with Overview CoreScope, temporary Overview Radio selection, return-to-Overview reset, preserved Network preference, radio-centered zoom9, health failure, offline and echo fallback. Synthetic services.
- meshmapper.browser.test.cjs and meshmapper-region.browser.test.cjs passed Network selection, PC location/recenter and layer parameters, saved region, compact fit, source isolation and fallback.
- corescope-fallback.native.test.cjs and overview-startup.native.test.cjs passed against built app.asar under matching Electron42.11.12 with isolated profiles and synthetic service responses.
- Windows x64 NSIS and portable builds completed.

No production profile or physical radio accessed. Existing installer visual-validation limitation and physical backlog acceptance remain open. Local candidate only; no stable release/tag published.
