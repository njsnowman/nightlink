## Changes

Initial workspace markup and CSS use a CoreScope loading surface and hide the local map/footer until map-source initialization. This prevents Radio map appearing while earlier scripts initialize. Source initialization clears the pending state and directly opens CoreScope online, or shows Radio map for offline/service failure or explicit selection. Saved Network preference and compact map-collapse behavior remain.
