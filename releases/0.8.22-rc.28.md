## Behavior

- Message text selects reply context, preserves the existing composer draft and focuses it. Received channel messages add the sender's advertised-name mention when it fits the 133-byte limit. No transmission occurs on selection.
- Hop badges open the selected message's route/map; missing repeater information remains explicitly unavailable. Broadcast/outgoing badges also offer route information without inventing a receiving path.
- Sender name/avatar retain contact-card actions and direct DM routing.
- Nested mentions and links retain their own actions, and text selection does not initiate a reply. Enter/Space on the message body selects reply.
- Detached DM body selects local reply context, hop button sends a path request for the matching message in that window's trusted snapshot, and name opens the contact card. Owner-dialog foreground handling is retained.
- Reply context is local UI context; channel addressing is a compatible sender mention, not protocol-level quote/thread metadata. Selecting reply does not replace a draft or truncate it to fit a mention.
