# NightLink 0.8.28-rc.61 candidate

Design pass, batch 3 (owner request, 2026-11-27: items 5, 6, 9 and 10). [Changelog](../CHANGELOG.md#unreleased). Previous candidate: [rc.60](0.8.28-rc.60.md). Unpublished candidate for owner evaluation.

## Scope added since rc.60

- Split view (`terminal-mrc.js`): F6 cycles a second window into a read-only pane (latest 60 lines, plain text without message ids, so reply, reaction and reading logic stay with the main log). There is a close button; the pane updates on full renders, which a new message in the split window triggers because its unread signature changes.
- Custom colours (`terminal-theme.js`): four tokens (`--t-white`, `--t-bright-cyan`, `--t-yellow`, `--t-blue`) set with CSSOM `setProperty` on `<html>`; CSP is unchanged. Values below 4.5:1 are refused and labelled "too low, not applied". The script loads in the main, detached DM and lock documents.
- Page art (`terminal-windows.js`): `PAGE_ART`, a one-line motif per page in the title bar, `aria-hidden`.
- Item 10 (compact layout): measured instead of rebuilt. At 760x560, Overview, Messages, Nodes, Map, Radio, Settings and split view have no horizontal overflow; the new elements have narrow-width rules.
