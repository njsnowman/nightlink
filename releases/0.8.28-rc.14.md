# Nightlink 0.8.28-rc.14 local diagnostic candidate

Tracks [#131](https://github.com/njsnowman/nightlink/issues/131) and [PR #133](https://github.com/njsnowman/nightlink/pull/133). [Changelog](../CHANGELOG.md). Previous candidate: [rc.13](0.8.28-rc.13.md).

## Scope

Includes rc.13 chat readability and text-size controls. Adds the owner-approved compact CoreScope live map at the upper right of terminal chat, replacing the node list, inside a blue ANSI-style frame. CoreScope navigation, packet lists and extra map controls are suppressed; map-provider attribution stays visible. Compact windows start collapsed. The iframe survives routine message renders and unloads when collapsed, offline, provider-hidden or outside terminal Messages. Other map views are unchanged.

The map-only adapter is restricted to an explicitly marked, exact-origin CoreScope live iframe. It adds no remote IPC or Node capabilities. See [implementation validation and limitations](../docs/chat-corescope.md).
