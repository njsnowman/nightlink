# Nightlink 0.8.23 — documentation patch preparation

Tracking: [#93](https://github.com/njsnowman/nightlink/issues/93), documentation [#92](https://github.com/njsnowman/nightlink/issues/92), [changelog](../CHANGELOG.md).

Scope: package the refreshed offline Help and About content, with current radio-workbench, public-ID, mention-alert and route-map guidance. Repository documentation reflects the public update feed and current release evidence. Radio, transport, security and installer implementation are unchanged from 0.8.22.

Publication status: draft preparation. The 0.8.22 owner exception is not extended to this version. Actual isolated installer lifecycle/multiple-DPI checks (#63) and production optional-lock re-enrollment/restart (#87) remain unverified. North Pole VM remains excluded. Do not describe this draft as a published or fully accepted installer release.

Both executables are unsigned. Startup lock controls app entry but does not encrypt history or backups. Optional CoreScope/MeshMapper, previews and update checks require internet; core radio messaging does not. Another client can consume the finite companion queue. Prior physical direct-trace evidence is inherited from unchanged code; no new radio test is performed for this documentation patch.

Exact source, artifacts and validation results will be appended after execution. Published 0.8.22 assets remain unchanged.
