# Nightlink 0.8.22-rc.29 installer design candidate

Status: local candidate; no stable publication or production installation.
Tracking: [#80](https://github.com/njsnowman/nightlink/issues/80), installer lifecycle gate [#63](https://github.com/njsnowman/nightlink/issues/63). [Changelog](../CHANGELOG.md), [design notes](../INSTALLER_DESIGN.md).
Source commit: e0c13e15f721bd07aeb446b9699fae3c24f380c1.

## Changes

Replace legacy cyan artwork with Switchboard near-black/amber/warm-white styling and regenerated header/sidebar artwork. Custom nsDialogs welcome, shortcut-options and completion pages use stage labels, Segoe UI headings and Consolas technical labels. Directory/progress pages use the matching theme; uninstaller wording/artwork updated. Native navigation controls remain to preserve Windows keyboard behavior. Per-user setup, no elevation, optional desktop shortcut, disabled automatic launch and retained application data configuration remain unchanged. Application messaging/radio source is unchanged from rc.28.
