# Nightlink 0.8.28-rc.16 local diagnostic candidate

Tracks [#134](https://github.com/njsnowman/nightlink/issues/134) and the [changelog](../CHANGELOG.md). Previous candidate: [rc.15](0.8.28-rc.15.md).

## Scope

- Remove the forced Overview navigation from startup and manual sync-completion handlers. In terminal Chat, avoid rebuilding the full page when synchronization completes; update message state through the existing render path, retaining conversation, draft and keyboard focus.
- Replace the short startup log with a roughly four-second BBS dial-up introduction: typed modem commands, an ANSI handshake graphic, staged introduction progress and the Nightlink logo. The modem sequence is explicitly simulated. Actual transport/sync state is shown on a separate live radio-status line.
- Add optional simulated modem tones under Settings > Dial-up intro sound. Off by default; respects quiet hours and stops when skipped. The introduction remains once per session, skippable by any key/click, disabled by preference, skipped under reduced motion and absent in Cards mode.

## Validation

The new startup navigation regression reproduced the original failure (actual Overview instead of Messages). After the fix it passed: startup sync preserves Chat, draft and focus; manual connection closes its dialog without changing Chat; a page selected during asynchronous startup bookkeeping remains selected.

BBS intro tests passed with synthetic radio events and a fake AudioContext: typed sequence, actual radio state updates, no navigation on completion, once per session, consumed skip key/click, compact fit, default-silent audio, opt-in playback/cancellation, quiet hours, reduced motion and Cards. No audible sound quality or physical-radio behavior is established by these tests.

Terminal-window browser checks, the 19-screen terminal accessibility audit, connection-dialog checks and 18 focused terminal/startup unit checks passed. Candidate full-unit/package validation pending.
