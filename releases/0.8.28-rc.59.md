# NightLink 0.8.28-rc.59 candidate

Design pass, batch 1 (owner request, 2026-11-27: items 1-3 of the enhancement list). [Changelog](../CHANGELOG.md#unreleased). Previous candidate: [rc.58](0.8.28-rc.58.md). Unpublished candidate for owner evaluation.

## Scope added since rc.58

- Command palette (`command-palette.js`): Ctrl+P, or `^P Go to` in the terminal key bar. It lists pages, channels, contacts (by card name) and actions: Search messages, Add or remove a channel, Device Center, Help and Switch interface. Ranking is prefix, then word prefix, then substring, then in-order letters. Accessible as a combobox and listbox with `aria-activedescendant`; Escape returns focus. Styled in both interfaces. Ctrl+K is unchanged (message Search).
- Nodes signal (`node-signal.js`): the full Nodes page shows LAST SNR with four bars (thresholds -10, -5, 0 and 5 dB) next to the value, and LAST ADVERT shows a relative age with the exact time in the tooltip. SNR comes from the last direct message received from the contact (the existing `live-ui.js` behaviour); otherwise it stays blank. The column remains hidden on Overview and in compact mode.
- Item 2 (unread markers in the channel lists) needed no change: `refreshUnreadBadges` already marks channels and contacts in the Cards sidebar, and the terminal chat window list shows per-window unread counts.
