## Behavior

CoreScope Overview, Network and #echo use validated companion-radio coordinates at zoom 11. Missing/invalid coordinates use a labeled regional fallback (39.44, -85.35) at zoom 9. Recenter controls return to the current radio-reported position. Identity/location changes update an active CoreScope viewport; ordinary message renders retain it. No computer-location permission or radio configuration changes are introduced.

Radio-reported position may be configured or stale. The interface labels it as radio-reported location rather than claiming a current GPS fix. CoreScope observer data remains separate from delivery acknowledgment.
