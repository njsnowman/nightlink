# Nightlink 0.8.30 stable release preparation

Tracks [#236](https://github.com/njsnowman/nightlink/issues/236) and the [changelog](../CHANGELOG.md#unreleased). This is a preparation record. Publication requires the owner's approval of the verified artifacts and of the physical-radio checks below.

## Scope

The changelog entries after v0.8.29 (2026-11-28), merged in #235 (merge commit `2d241f4`):

- Terminal style pass:
  - chat density (Normal, Compact, Roomy)
  - signal symbols (▲ ◆ ▼)
  - retro animation (blinking cursor; off under reduced motion)
  - title bar banner text
  - caller ID in the node panel
  - full-name tooltips
  - Nodes row highlight
  - button sizes
- Terminal chat:
  - day separators (Today, Yesterday, date)
  - ★ before messages from favourite contacts
- Cards design pass:
  - sidebar icons
  - settings toggles
  - activity timeline and filters
  - offline map note
  - coloured avatars and favourite ring
  - message grouping
  - SNR quality word
  - messages sparkline
  - battery trend
  - header de-duplication
  - Signal Rail pills
  - Reply, Copy and Path on hover or focus
  - empty states for chat and contacts
- Cards glass (owner request): Settings > Interface > Glass, Frosted (default), Liquid or Off. `prefers-reduced-transparency` shows solid panels.
- Fixes made during review:
  - The reading anchor is kept when Cards regroups rows.
  - The Signal Rail no longer reduces the chat height in compact layouts.
  - Own messages are no longer right-aligned (owner report).
  - The sidebar and header glass sit on a `::before` layer so fixed flyouts are not clipped.

Version: `package.json` 0.8.30. Installations of 0.8.29 are offered 0.8.30.

## Draft release notes

Nightlink 0.8.30

**Cards**
- Glass: Settings > Interface > Glass offers Frosted (default), Liquid or Off. When Windows transparency effects are turned off, panels are solid.
- Design pass:
  - sidebar icons
  - coloured avatars with a ring for favourites
  - grouped consecutive messages
  - Reply, Copy and Path on hover
  - battery trend and messages sparkline
  - SNR quality word
  - Signal Rail pills
  - activity timeline with filters
  - clearer empty states

**Terminal**
- Day separators in chat, and ★ before messages from favourite contacts.
- Settings:
  - chat density
  - signal symbols (▲ ◆ ▼)
  - retro blinking cursor
  - your own title bar banner text

**Known limits**
The Windows executables are unsigned. #116 remains open. Channel send confidence is deferred to #230.

To upgrade, export a Nightlink backup, quit Nightlink from the tray icon, and run the Windows installer. Check the downloads against the attached SHA256SUMS.txt.
