# Nightlink 0.8.28-rc.1 diagnostic candidate

Issue: [#131](https://github.com/njsnowman/nightlink/issues/131). Base: [0.8.27-rc.10](0.8.27-rc.10.md) lineage (`39d44cd`); 0.8.27 continues in [#120](https://github.com/njsnowman/nightlink/pull/120). [Changelog](../CHANGELOG.md).

## Scope

Terminal interface as the default; the rc.11 card design stays selectable in Settings > Interface (Cards).

- Foundation: VGA 16-color tokens, monospace type, frames with titles on the border, menu bar and function-key bar, dithered ANSI logo (`terminal.css`, `terminal.js`, `terminal-logo.js`).
- Overview as the BBS main menu with hotkeys (`terminal-menu.js`).
- Messages as MRC (Mesh Relay Chat): window list, `HH:MM <nick>` scrollback, delivery lines that open the message path, node list, `/commands`, 133-byte counter (`terminal-mrc.js`).
- Text-mode windows for Radio, Settings, Help, Nodes, Network map, Activity, Direct Messages, Search and every dialog, including Device Center and Propagation Monitor (`terminal-windows.js`).
- ANSI path view in the Message path dialog and a collapsible ANSI node map on the Network map page. Both use stored evidence only.
- Title bars in the detached DM window and on the startup lock.
