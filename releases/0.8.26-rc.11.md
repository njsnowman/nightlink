# Nightlink 0.8.26-rc.11 - Radio Tools design

Tracks [#111](https://github.com/njsnowman/nightlink/issues/111) and [PR #110](https://github.com/njsnowman/nightlink/pull/110).

Radio Tools now groups its nine existing actions into device/setup, contacts/discovery and broadcast sections, with contact removal in a separate maintenance row. Action cards use matching SVG icons, descriptions, consistent alignment and clear keyboard focus. The header reflects the selected companion and connection state without querying the radio. Cards retain their original DOM handlers, confirmation flows and connection guards. Contact-sharing, import and advert sheets receive matching visible controls.

Responsive layouts use three, two or one column; enlarged text is supported without horizontal overflow. The design uses existing accent/surface tokens. Opening and navigating the tool panel does not initiate radio traffic.

Validation and artifact provenance follow below. Existing release limits remain: physical configuration writes/readback and direct infrastructure USB are not established by these visual tests. No stable publication is included.

Source validation: 287 unit tests pass. Device Center, combined Echo and Radio Tools design browser suites pass. Original advert confirmation, QR-image preview/import invalidation and window bounds browser checks also pass. Visual inspection covered 1440, 1024, 760 and 480 pixel layouts, including enlarged text. All fixtures use synthetic radios.
