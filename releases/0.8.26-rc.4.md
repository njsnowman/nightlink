# Nightlink 0.8.26-rc.4 - Device Center alignment candidate

Tracking: [#109](https://github.com/njsnowman/nightlink/issues/109); implementation [PR #110](https://github.com/njsnowman/nightlink/pull/110).

Centers Device Center headings, captions, selected values, status summaries and configuration fields. Uses equal-width action columns, consistent 48 px controls and vertical center alignment. Authentication, review and file-import actions share the same layout rhythm. Compact layouts retain balanced spacing and responsive columns. Radio command behavior is unchanged.

Validation: Device Center rendered checks pass at 1440, 1024 and 760 px with compact mode and 130% reading scale; desktop and compact screenshots were visually inspected. Exact package and existing feature checks are recorded after the build below. Physical-radio acceptance remains open as documented in rc.2; no hardware configuration was changed. This is a local candidate, not a stable release.
