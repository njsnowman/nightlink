# Nightlink 0.8.28-rc.41 local candidate

Tracks [volunteer site ideas #189](https://github.com/njsnowman/nightlink/issues/189), [changelog](../CHANGELOG.md), [workflow](../docs/project-planner.md), [full handbook](../docs/nightlink-full-help.html) and [design standard](../DESIGN_SYSTEM.md). Based on rc.40. Queen City Con unchanged.

Operations centers on occasional volunteer site work. Try a location selects a stored/manual reference and proposed pin, uses feet for heights and miles for radius/distance, and explicitly previews direct terrain/LOS plus local modeled coverage. Keep creates an independent format-8 plan; labels/notes can change without recalculation, while changed RF/geometry inputs invalidate the preview. Run, Cancel, cached-only terrain and provider errors never save partial results. A simple standalone site note replaces default staffing/schedule paperwork. A later field visit, detailed seven-stage planning, engineering and installation records remain optional. Existing source/history and formal acceptance requirements are preserved. The library/menu and 45-topic offline help describe volunteer use.
