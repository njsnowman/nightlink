## Changes

Per-radio local event replay, raw received-packet inspection, passive placement sessions and reception history; attributed raster MBTiles/JSON imports with coverage navigation and CoreScope fallback; optional local whisper.cpp dictation with editable review, recording cancellation and optional local incoming-DM reading. Main message views immediately follow the newest message without a transient Jump to latest prompt.

## Automated validation

120 unit tests passed. Browser checks passed: diagnostics.browser.test.cjs, voice.browser.test.cjs, connection-layout.browser.test.cjs, navigation.browser.test.cjs, smoke.test.cjs and offline-streets.browser.test.cjs. Packaged checks passed: diagnostics.native.test.cjs and tray.native.test.cjs before the final scroll/CSS-only adjustment; latest-scroll.test.cjs, voice-inference.native.test.cjs and offline-maps.native.test.cjs passed against the final rebuilt app.asar using Electron 42.11.12.

Real whisper.cpp v1.9.2 CPU inference with ggml-tiny.en passed through trusted IPC using an upstream public speech sample and simulated microphone input. Recording/review/cancel, compact bounds, concurrency exclusion, idle recovery and no radio transmission were checked. This was not a physical microphone test.

Offline checks used a locally rendered, attributed 58-tile OSM extract at zooms 15–17 and a test-owned file picker. Read-only SQLite MBTiles import, TMS conversion, file integrity, persisted raster rendering, all three map surfaces, coverage navigation and unavailable-area status passed. No bulk standard OSM tile download was used.

## Physical-radio evidence

Candidate source 87008d7733220d8f3fa480f7bca351b877d21b7a synchronized with Heltec V4.3 OLED, firmware v1.17.1-d929643, over USB COM23. A 122-second receive-only session had zero disconnects, one valid RX packet, one placement sample and one observed path group. No messages/adverts or firmware/settings writes were initiated. This verifies capture plumbing on this radio; one sample does not establish placement accuracy or endurance. Final-source differences concern display, evidence flush on Quit and scrolling; transport/parser code was unchanged. The final binary was not independently physically retested.

Normal Quit released COM23; read-only open/close with DTR/RTS disabled passed. Backup merge through the installed app added zero messages, skipped none and verified existing IDs after reload. The normal app was reopened/reconnected with 25 retained messages. Private data remains outside the repository.

## Limits and acceptance

All release-blocking criteria for this scope are resolved. Voice runtime/model must be supplied separately; offline map packs are not bundled and cover only their supplied areas/zooms. Offline detection cannot inspect a loaded cross-origin CoreScope error page; manual Radio map selection remains available. Reception measurements are last-link observations, not complete per-hop signal traces. Replay is local and does not retransmit. No new multi-hour endurance claim is made.
