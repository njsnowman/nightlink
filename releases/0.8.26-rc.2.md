# Nightlink 0.8.26-rc.2 — Device Center candidate

Tracking: [#109](https://github.com/njsnowman/nightlink/issues/109). Research, protocol sources and limits: [device management](../docs/device-management.md).

Adds Radio → Manage devices, Radio Tools → Device Center and repeater/room contact options → Manage device. Supports connected companion configuration, authenticated infrastructure CLI administration and a distinct direct text-CLI USB setup connection.

Settings are inspected explicitly, staged, reviewed as before/after values and checked again for drift before applying. Writes run sequentially with setting readback, stop on uncertainty and report partial results. Companion RF writes preserve the observed repeat flag. Remote administrator permission is required for structured writes. Credentials are session-only and sensitive advanced output is suppressed. All prior Echo buttons, contact preservation/removal controls and chat features remain required package assets.
