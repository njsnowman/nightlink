# Nightlink 0.8.22-rc.6 — local candidate

Tracking: https://github.com/njsnowman/nightlink/issues/59

Source commit: 6b957852be883fc54c59e2ceaf765edfaa767c7d

## Changes

Radio map starts at valid radio-reported coordinates at zoom 12. Contact updates retain the user's pan and zoom; Recenter restores the radio view. Without radio coordinates, the saved view or Batesville/Cincinnati/Indianapolis regional view is used. Network offers MeshMapper CVG alongside CoreScope and Radio map. The read-only embed uses the documented CVG endpoint, radio coordinates when available, zoom 12 and geofence=0. Open full map opens the fixed CVG website. Remote-service or Internet failure falls back to Radio map without overwriting the selected source.

## Validation

- Six health/location unit tests passed: node --test corescope-health.test.cjs corescope-location.test.cjs.
- meshmapper.browser.test.cjs passed: centering, pan preservation, Recenter, embed parameters, Network-only selection, 760×560 and 1100×740 at 130% text size without outer overflow, offline/service fallback.
- corescope-fallback.browser.test.cjs and echo-workspace.test.cjs passed during implementation.
- meshmapper.native.test.cjs and corescope-fallback.native.test.cjs passed against the built app.asar under Electron 42.11.12 using isolated profiles. Confirmed main-frame health IPC, unavailable-service fallback and no native bridge in remote frames. These are simulated service/location checks, with no radio access.
- The packaged executable cannot host the fixture argument as a diagnostic Electron executable can; initial fixture launches exited. Packaged app.asar checks were rerun successfully under the matching diagnostic runtime.
- Windows x64 NSIS and portable builds completed successfully.
- Point-in-time public CVG embed request returned HTTP 200 and HTML identifying MeshMapper. This does not establish regional coverage or full WebGL rendering on every GPU.

## Limitations

Radio coordinates may be configured or stale; no fresh GPS fix is asserted. MeshMapper is an Internet-dependent, read-only WebGL embed; local offline coverage must already exist for detailed fallback maps. No physical-radio validation was performed. Existing backlog acceptance in issue #49 remains open. This is a local candidate, not a stable release or tag.

Embedding reference: https://wiki.meshmapper.net/embedding/
