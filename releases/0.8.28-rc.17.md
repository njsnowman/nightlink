# Nightlink 0.8.28-rc.17 local diagnostic candidate

Tracks [#136](https://github.com/njsnowman/nightlink/issues/136) and the [changelog](../CHANGELOG.md). Previous candidate: [rc.16](0.8.28-rc.16.md).

## Scope

Use the owner's approved original 6.1-second modem-to-laser WAV as the startup sound. Enable it by default while retaining explicit sound-off and quiet-hours preferences. Keep the loading screen until the media `ended` event; the visual timer and key/click input cannot stop or bypass active playback.

Autoplay denial and paused audio display a start/resume prompt. Failed or stalled media has a bounded fallback instead of permanently blocking startup. Reduced motion uses a static screen while the sound completes. The existing once-per-session, startup-off, Cards and radio-sync navigation behavior is retained.

Asset: `startup-modem-laser.wav`, mono 44,100 Hz 16-bit PCM, 6.1 seconds. SHA-256 `a273e583bc3a4be31cc33619fe35ae30c31827aea5bb13e1362fc85c33833ce0`. `node art/audio/make-startup-sound.cjs` regenerated the exact approved bytes. No third-party sample audio is used.
