# Nightlink 0.8.28-rc.25 local candidate

Tracks [RF suite #157](https://github.com/njsnowman/nightlink/issues/157), [changelog](../CHANGELOG.md) and [methods/workflow](../docs/rf-suite.md). Primary app based on rc.24; Queen City Con unchanged. Stopped live-operations-console work excluded.

Scope: explicit Open-Meteo/Copernicus GLO-90 terrain retrieval, persistent offline point cache and point-weighted quota reservations; shared-assumption multi-destination repeater ranking; sampled Bullington diffraction plus free-space coverage; geometric antenna-height optimization/practical-height comparisons; manually confirmed endpoint tests with immutable prediction/setup snapshots and residual statistics/chart; printable per-site deployment packets. Source resolution, documented dataset release, datum, fetch time and model limitations remain visible. Missing/stale inputs are unresolved. Background sync completion preserves the Operations workspace and terrain job.

Planner database version 3 retains earlier plans; older builds cannot open it. Backup format 3 accepts imports 1–3. Export before upgrading if an older build must remain usable. Terrain cache is a separate database with bounded retention. Terrain retrieval is opt-in and sends requested coordinates to the provider's public endpoint; its non-commercial terms and conservative coordinate-weighted quotas apply.
