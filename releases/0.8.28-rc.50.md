# Nightlink 0.8.28-rc.50 local candidate

Tracks [chat performance #207](https://github.com/njsnowman/nightlink/issues/207) and the [changelog](../CHANGELOG.md).

CoreScope starts collapsed in Terminal chat. Opening the pane loads the map. Collapsing it releases the iframe. Terminal chat avoids building the hidden Cards transcript, and reaction matching only examines conversations represented in the displayed rows. A conversation without reactions requires no message hashes. The candidate includes the Terminal reaction display recovered from the installed rc.49 package.

The installed rc.49 graphics process used 4.84 CPU seconds over five seconds while the CoreScope map was open and less than 0.01 CPU seconds in a five-second sample after collapsing the map. A later eight-second sample with a message-path map open used 7.75 CPU seconds. Closing that dialog reduced the next five-second sample to 0.05 CPU seconds. These are live process observations from this computer. The candidate reduces automatic map use and chat redraw work. Graphics load while actively viewing a map remains a limitation on this computer. Browser and packaged checks use synthetic chat data.

A synthetic comparison loaded 3,000 ordinary messages and appended 12 more. Median Terminal redraw time in that run was 671 ms using the installed code and 350 ms using the candidate code. The candidate mounted 300 Terminal rows and zero hidden Cards rows. The installed code mounted 300 Terminal rows and 120 hidden Cards rows. A cold reaction pass over 3,000 ordinary messages took 66 ms with the installed code and 2 ms with the candidate code. The candidate issued zero digest calls during the benchmark.

The unit suite completed with 531 passes and one existing skip. Terminal live following and reply checks passed. The Cards attention workflow passed after changing its reload wait to match the document readiness needed by the test.

CoreScope lifecycle, Contact Book, Cards and detached-DM reactions, and Terminal interface checks passed in the browser. The packaged Electron renderer passed on-demand map loading and release, Terminal and Cards reactions, and switching interfaces with 3,001 synthetic messages. The packaged check used an isolated profile and blocked external HTTP and radio commands. Live-radio and installer execution checks for rc.50 remain pending.

The accessibility audit passed 146 screens, including the main workspace, detached DM and startup lock.
