# Nightlink 0.8.22

Tracking: [#74](https://github.com/njsnowman/nightlink/issues/74), [changelog](../CHANGELOG.md). Release preparation follows the owner's explicit decision to publish despite remaining validation gaps documented in RELEASE_READINESS.md. The previous installer hold is lifted for this release only; North Pole VM is excluded.

Scope consolidates the local candidates through rc.43: messaging/navigation/readability, public-ID copying, mention chime/highlighting, directional message-hop map replay, Radio workbench/status, offline/history/backup improvements, external map/preview controls, optional startup lock and installer design.

Known limitations to retain in public notes: actual isolated installer lifecycle and multiple-DPI testing are unverified (#63); production optional-lock re-enrollment/restart remains unverified (#87), although isolated Windows protected-store/upgrade fixtures passed. App lock does not encrypt existing message history. Earlier physical trace timeouts remain unexplained; a direct Heltec/Batesville trace passed, while multihop/hardware-wide reliability is not established. CoreScope/MeshMapper/page previews require internet; downloaded map packs are needed for offline street coverage. Another client may consume the radio's finite retained queue. No claim of comprehensive hardware or installer compatibility.

Source commit, exact artifact hashes, final checks and public URLs follow after execution. Private backups, credentials and messages are excluded from this repository and release assets.
