## Result
Overview and main Messages render at the latest message instead of restoring an older saved anchor or unread boundary. Incoming messages follow to the bottom automatically. Separate DM-window reading behavior and history storage remain unchanged. Earlier connection-flow changes from 0.8.17 remain included. Advanced features in #43 are excluded.

## Validation
- 114 existing unit tests passed.
- latest-scroll.test.cjs passed in isolated browser and against packaged app.asar with matching Electron: 120 retained messages, saved old anchors/unread boundary, Overview/Messages switching, incoming arrivals without clicking, and 760×560 / 1320×860 bounds.
- attention.browser.test.cjs passed: unread/mute persistence, independent sounds, mention navigation, silent catchup and focused DM reading, with updated main-view follow-latest expectations.
- navigation.browser.test.cjs passed: 350 contacts / 20 channels, four sizes and compact modes.
- drafts.native.test.cjs passed against the package: DM draft IPC, persistence, reading anchors and latest jump.
- NSIS installer and portable builds completed.

No physical radio or normal user profile was accessed for these checks. The fix changes rendering only; simulated arrivals are not physical RF evidence. Installation into the user's normal profile was not automated. Acceptance criteria for this display-only fix passed.
