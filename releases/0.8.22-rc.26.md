## Changes

Mount up to 120 conversation rows with earlier/newer archive navigation. Search targets the correct archive page; new arrivals return to the latest page. Stored-history retention limits are unchanged. Reuse unchanged native-DM snapshots and message elements while preserving drafts and delivery-state changes. Reuse map frames for redundant source/online events. Pause Nightlink health/recovery probes while hidden. Avoid rebuilding unchanged signal-chart/channel controls. Update the clock at minute boundaries. Display bounded, memory-only phase timings in Radio Health without message contents or identifiers. Synchronization command order is unchanged; telemetry and final queue recovery now have distinct progress labels.

## Limitations and acceptance

No physical-radio validation, normal-profile upgrade or installer execution performed for this candidate. Cold executable launch latency was not benchmarked. Renderer phase timings are not process startup timings; iframe page load is not live packet readiness. Provider startup delay remains open in #77. External iframe stream/render activity remains provider-controlled; Electron radio/background throttling was not changed. Physical nonempty M1 backlog confirmation (#49) and installer lifecycle validation (#63) remain release blockers. Do not publish a stable release on the basis of these synthetic results.
