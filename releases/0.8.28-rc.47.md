# Nightlink 0.8.28-rc.47 local candidate

Tracks [site/height comparison #201](https://github.com/njsnowman/nightlink/issues/201), [changelog](../CHANGELOG.md), [design standard](../DESIGN_SYSTEM.md) and [local tools guide](../docs/local-planning-guide.md). Based on rc.46. Queen City Con unchanged.

Local planning tools gains Compare sites: choose up to four proposed project sites and one to eight tested AGL heights (5–300 ft), set an explicit area goal, run a bounded local comparison, pick a tested option and export a field-visit sheet. Two location frames fit across desktop windows and stack below 1100px. The same common grid is used for each option. Results retain unknown inputs and distinguish potential combined area/added percentage points from reciprocal saved-path backhaul. Both backhaul endpoints use study site profiles, with the tested candidate height applied explicitly; per-path height overrides are omitted for this comparison.

A shortlist requires resolved baseline/candidate coverage inputs, new known gap samples served, reciprocal backhaul meeting budget, the entered area goal and every selected destination meeting budget. Per location, the lowest qualifying tested height is shown. Locations are ordered by tested height, then added samples and backhaul reserve. This is not an exhaustive minimum, practical siting optimum or field verification. Access, power, mounting feasibility and costs are not inferred.

The existing local model recomputes from stored radial traces and sampled endpoint paths. No new terrain/network/radio action or CloudRF integration is added. The local engines retain their previous assumptions. The field sheet includes coordinates, equipment, tested height, selected assumptions, input signature, tradeoffs, path profile when sampled geometry is available and visit/test checks. Export the study bundle alongside it for complete source assumptions.

Changing inputs invalidates results; cancellation returns no partial comparison. Theme changes retain current results. Comparison options round trip in independent local-study bundles; results are rerun after reopening. Comparison selection does not invalidate unrelated measurement signatures. Explicit latest-snapshot selection prunes deleted site/path overrides transactionally. Source project DB/backups remain 8, local study DB remains 1; source plans/history/physical evidence are not changed by comparing or exporting.
