Native DM windows temporarily release their parent relationship while the shared workspace dialog is open. The workspace is shown and focused; dialog dismissal restores normal ownership. The shared dialog observer covers contact cards, secondary menus and message delivery details. Conversation state and drafts remain in the existing DM renderer.

Verified the DM has no parent during contact-card display, regains its parent after dismissal, retains contact notes and uses one DM window after repeated contact actions. The test waits for all renderer scripts to load before fixture setup. No physical radio or production profile was used.
