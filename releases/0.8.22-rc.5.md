# Nightlink 0.8.22-rc.5 — local Network fallback candidate

Tracked in [#58](https://github.com/njsnowman/nightlink/issues/58), [PR #52](https://github.com/njsnowman/nightlink/pull/52). See [changelog](../CHANGELOG.md) and [map sources](../CORESCOPE_MAP.md). Application source: ac2af9dd47e92e660b3e9d6560550ab3fa574d46. Later commits only record validation.

## Behavior

Network CoreScope starts/recenters on valid radio-reported coordinates at zoom9, two levels wider than the prior zoom11. Overview and echo retain zoom11; regional fallback remains zoom9.

Windows main process checks the fixed public /api/health endpoint: six-second timeout, successful JSON status ok, 128KiB response cap, no arbitrary URL argument. Trusted main-frame IPC only; concurrent checks coalesced with a five-second result cache. Active CoreScope views check immediately and every30seconds. Endpoint failure automatically switches Network/Overview/echo to local Radio map even if navigator.onLine remains true or an iframe load event has fired. Checks stop on source/view/frame removal and late results cannot change removed views. Preferred source remains unchanged. Online events/Reload can retry; a manual local-map preference is respected.

Endpoint availability does not prove functioning map tiles, live WebSocket updates or observer coverage. Local street detail offline requires an installed map pack for that area. No radio configuration changes.

## Validation

Five health/location unit tests passed: expected JSON, HTTP/invalid body/network/timeout/oversize failures, child-frame denial/cache/coalescing, validated coordinates and Network-specific zoom. corescope-fallback.browser.test.cjs passed healthy/failing service transitions despite online state and iframe load, local map visibility, preferred source preservation, offline handling, echo fallback and cleanup. echo-workspace.test.cjs passed after changing only Network zoom expectation and making its native health fixture deterministic.

Final app.asar with Electron42.11.12 passed corescope-fallback.native.test.cjs: native bridge with synthetic health, zoom9, no native health bridge in remote iframe, service failure fallback while online, retained preference. Packaged echo-workspace.test.cjs passed split/lifecycle/divider/offline restoration and compact130%text checks. All fixtures used isolated profiles and synthetic service/radio state. No physical-radio or production-profile access. A direct public endpoint check returned HTTP200/status ok during implementation; it is a point-in-time observation, not uptime evidence.
