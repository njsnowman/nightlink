## Scope

The owner supplied NIGHTLINK logo artwork on 2026-11-03 and asked for it to be used. Presentation only.

- Source kept at `art/ansi/source/nightlink-logo-owner.webp` (2000 x 667).
- `art/ansi/make-logo-art.py` crops the artwork (39,146)-(1968,463), reduces it to 240 x 39 pixels with a box filter, and maps each pixel to the nearest VGA color without dithering. It writes `terminal-logo-art.js` (rows of hex palette indices), `nightlink-logo-v2.ans` (CP437 half blocks, 240 columns, classic SGR, no iCE colors), `nightlink-logo-v2-80.ans` (80 columns, reduced detail) and PNG previews.
- terminal-logo.js `logo()` draws the art as SVG rects, merging same-color runs per row; black is transparent. Up to 960 px wide in the main menu. The chrome logo (rc.5) is the fallback if the data module is absent.
- The ANSI writer maps VGA indices to ANSI background numbers (the orders differ); a first draft used the VGA index directly and showed red and brown, fixed before commit.
