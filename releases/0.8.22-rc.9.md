## Behavior

Network → Region and Settings → MeshMapper region save a three-letter code locally. CVG is the default. The selected code updates the MeshMapper embed, labels, full-map link and health endpoint, and persists across reload/restart. Region choice remains saved when the service is unavailable; Radio map provides fallback. Code format is validated in renderer and native handlers before constructing HTTPS MeshMapper subdomains. Native health checks coalesce/cache by region, and remote frames remain isolated from native bridges. Radio location centering is independent of the regional data source.

- meshmapper-region.browser.test.cjs passed: default CVG, save lowercase ind as IND, updated embed/label/full-map argument, persistence after reload, Settings value, radio centering, compact130% fit, service/offline fallback retaining choice. External maps were simulated.

## Limitations

A valid three-letter code does not guarantee a provisioned or available MeshMapper region. Region maps require Internet/WebGL. Offline street-map detail depends on downloaded coverage. No radio configuration, profile migration, community branding or physical-radio behavior changed in this candidate. Existing physical backlog acceptance in #49 remains open. Local candidate only; no stable release/tag published.
