# 0.8.22-rc.22 — Switchboard local candidate

Tracking: [#75](https://github.com/njsnowman/nightlink/issues/75). Changelog: [Unreleased](../CHANGELOG.md).

Implements the selected Switchboard layout: black industrial surfaces, amber default for unset accents, retained saved accent choices, compact channel tabs, flat message rows with round avatars and boxed hop metadata, and a passive last-hour SNR summary below the map. The graph uses actual retained evidence; unknown intervals are not interpolated.

Validation: 172 unit tests passed initially; the asset test failed while the shell stylesheet was still being written and passed after integration (173 total passing checks). Switchboard browser presentation fixture passed with synthetic state, channel selection, saved accent, passive graph empty and populated states, viewport fit, and DM rendering. Existing Overview layout fixture passed four viewport sizes, normal/compact modes at 130% text. Source native theme/contact/DM fixture passed with an isolated synthetic profile. No physical-radio test was performed for this presentation change.

Local candidate only. Stable publication remains blocked by existing physical M1 queue recovery and installer lifecycle acceptance criteria. Artifact hashes and matching source revision will be recorded after packaging.
