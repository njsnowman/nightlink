# Nightlink 0.8.5-rc.4 validation record

Status: diagnostic candidate; no GitHub release published.
Tracking: https://github.com/njsnowman/nightlink/issues/1

## Report and cause

Reported: Synchronization stopped at command 31, GATT operation already in progress.

A transport race was reproduced: a characteristic notification can arrive before writeValueWithResponse resolves. The old implementation released the command lock on notification receipt, allowing the next handshake or synchronization write to overlap the outstanding GATT write. The candidate retains the lock until both operations complete and prevents cancelled commands from writing through a newer connection.

## Validation

- Transport tests: passed notification-before-write-completion and rejection-after-early-response cases.
- Full automated suite: 49 passed.
- Browser integration with delayed write acknowledgments and overlap rejection: passed.
- Packaged Windows: passed handshake and full synchronization with notifications arriving before delayed GATT write completion. Commands 1, 22, 31, 10, 4, 20, 10 completed with zero overlapping writes.
- Physical-radio confirmation: pending. Issue #1 remains open and release-blocking.
