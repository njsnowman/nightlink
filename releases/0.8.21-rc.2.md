# Nightlink 0.8.21-rc.2 — local visual candidate

Tracked in [#51](https://github.com/njsnowman/nightlink/issues/51), [PR #52](https://github.com/njsnowman/nightlink/pull/52). Application source: bfab574eebdb1770451c7fa65cefaab44581b194; later commits contain tests and records only.

## Changes

Apply the user-approved hybrid concept: black/navy glass surfaces, cyan panel accents, original SVG navigation, readable chat bubbles, compact icon navigation and restrained connection-state decoration. The signal ring animates only during connection/synchronization and honors reduced motion. Device commands, history and on-air protocol remain unchanged. Native and floating DM colors and bubble spacing are aligned. Compact More is anchored to current navigation geometry with internal scrolling. Existing Radio destination, regional CoreScope viewport and collapsible Overview map remain. No mockup-only online counts, route lines or telemetry were introduced.

## Validation

overview-layout.browser.test.cjs and navigation.browser.test.cjs passed across supported windows and compact/normal modes at 130% text. CoreScope fixture checks passed regional URL, iframe isolation, source switching and offline behavior. Connection-layout browser checks passed idle/sync/error/ready at 760×560, 920×700 and 1320×860. Simulated GATT smoke passed sync/messages/ACK/history/reconnect. signal-console.browser.test.cjs passed compact keyboard More navigation, viewport bounds, accessible Radio control and long DM wrapping at 130% text, using a simulated DM bridge.

The final built app.asar passed overview-layout.native.test.cjs with Electron 42.11.12 at 760×560 and 1320×860. Packaged latest-scroll checks passed before the final More/DM spacing refinements; these do not alter scrolling code. Implementation previews use illustrative messages in an isolated browser, not user history. No production profile or physical radio was used in this design validation.

This is a local candidate, not a stable publication. It excludes the pending reconnect patch in PR #50; unresolved backlog investigation #49 remains open. No connection fix or new physical-radio result is claimed. Current installed app was not replaced.
