# Nightlink 0.8.22-rc.11 — local candidate

## Change and validation

The main workspace opens on Overview instead of restoring the last visited page. Saved conversation selection, reading state and other preferences remain in storage. Explicit navigation after launch is unchanged.

overview-startup.native.test.cjs passed against source and built app.asar under matching Electron42.11.12 using an isolated profile: select a conversation, save Settings as last page, reload, verify Overview and active navigation while retaining selected conversation and IND map preference. Synthetic state only, no radio access. Windows x64 NSIS and portable builds completed successfully.

## Limitations

Installer design/behavior is unchanged from rc.10. Actual wizard-page visual validation remains pending due the Windows inspection helper ownership error documented in [rc.10](0.8.22-rc.10.md); full upgrade/uninstall and multiple-DPI testing were not performed. Existing physical backlog acceptance remains open in #49. Local candidate only; no stable release/tag published. Installed application/profile and radio settings were not changed.
