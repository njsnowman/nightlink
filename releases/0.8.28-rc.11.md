# Nightlink 0.8.28-rc.11 diagnostic candidate

Issue: [#131](https://github.com/njsnowman/nightlink/issues/131). PR: [#132](https://github.com/njsnowman/nightlink/pull/132). Previous candidate: [rc.10](0.8.28-rc.10.md) (superseded before testing; its header row and start-up screen are included). [Changelog](../CHANGELOG.md).

## Scope

Owner request on 2026-11-03: the header row, the start-up sequence, then the rest of the enhancement list. Presentation and terminal-mode input only; no radio, storage or delivery changes.

- Fix from rc.10: the bracketed header rule overrode `[hidden]`, so hiding the RF indicator in Settings had no effect (`propagation.browser.test.cjs`, CI run 41586610783). Hidden header controls are `display: none` again.
- Detached DM (CSS only): `HH:MM <nick> text` lines; outgoing marked `>>> <You>`; hop count as `[n hops]`; delivery state as a `└─` follow-up coloured by state; avatars and bubble chrome hidden. `outgoing-message.browser.test.cjs` checks the card layout and now opts into Cards like the other card suites.
- Help: topics are menu rows with a cyan selected bar; the article has a double frame and a yellow title; PgDn/PgUp move between topics; the key line lists them.
- Retro sound pack (`terminal-sound.js`, off by default): with Settings > Sound pack = Retro, `sent.wav`, `dm.wav` and `mention.wav` play as short square-wave patterns (each at most 0.6 s) via Web Audio; only `HTMLAudioElement.play` for those files is intercepted, so the existing mute, quiet-hours and per-feature switches still decide whether a sound plays. A short chirp plays when the radio becomes synchronized; it is not governed by quiet hours.
- Empty Nodes and Direct Messages pages show `aria-hidden` ANSI art; the pages already state the empty state in text.
- Keyboard: arrow keys move through the main menu and through table rows on page windows; `/` opens message search, or the MRC command line on Messages. Inactive while typing or with a dialog open.
- MRC: Tab completes nicks and `#channels` and cycles on repeat; `/whois <name>` prints the stored type, route, signal, last advert and advertised location; lines mentioning your name (`name`, `@name`, `[name]`) get a yellow edge and text.

Not done: a sign-off screen on quit. The quit path waits on saving monitor state (rc.10 of 0.8.27); adding a screen there was left out.
