## Behavior

Nodes and Radio Tools offer Remove all except favorites. The preview lists the snapshot of exact contacts to remove and favorites to keep. A separate acknowledgement is required before confirmation. If no loaded contacts are favorites, the preview explicitly warns that every listed contact will be removed. If all are favorites, removal is disabled.

Removal uses sequential full-key single-contact commands with the existing complete contact-list readback after each accepted removal. A favorite added before a queued delete command executes is skipped. Originally protected favorites and contacts discovered after preview are outside the removal snapshot. Closing the dialog or selecting Stop prevents subsequent commands after the current operation. Errors, changed radio identity/generation and active sends stop the batch; the result shows verified partial progress and does not automatically retry. Saved histories and personal contact details stay local.

The #echo conversation has !test, !spam, !echo and !yolo buttons. An explicit click sends exactly the selected command through normal delivery handling without changing the composer draft. Other channels and DMs hide the buttons. Offline, synchronization, active send, radio configuration, bulk contact removal and missing-channel states block sends. Rendering never sends a command.
