## Changes

Add approved ice-blue post-login vault animation: locking ring rotation, six retracting bolts, door opening into Overview. Only successful app-lock authentication triggers it. Skip button/Escape continue immediately; OS reduced-motion bypasses animation. Native entry checks verified pending login; four-second native fallback opens Overview if renderer presentation stalls. Lock document retains restricted preload and cleared credentials. Ordinary unlocked startup and failed login do not animate. No audio or external resources added.

- security.native.test.cjs passed against source and built app.asar under matching Electron42.11.12: actual Windows DPAPI enrollment, lock/bridge isolation, failed login without animation, rejected pre-auth entry, recovery login with vault before workspace, authenticator login with stalled animation and native fallback, disable/restart and corrupt-state fail-closed. ## Limitations

Animation is decorative and does not add encryption or authentication strength. Existing app-lock boundary remains documented in SECURITY.md. No production profile, real user credentials or physical radio accessed/changed. Prior installer visual-validation limitation and physical backlog acceptance in #49 remain open. Local candidate only; no stable release/tag published.
