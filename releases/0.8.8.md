# Nightlink 0.8.8 release record

Tracking: https://github.com/njsnowman/nightlink/issues/14
Status: validation complete; publication pending.

## Scope

Backup and restore from PR #13, tracked in #12: native Windows Save, versioned local JSON export, restore preview, duplicate prevention, preservation of existing cards/preferences, and interrupted-restore recovery.

## Compatibility

Contact storage upgrades from IndexedDB version 1 to 2 while preserving cards. Older Nightlink versions requesting version 1 may not open upgraded contact cards. Close older clients before upgrading and continue using 0.8.8 or later for contact cards. This does not change radio firmware.

## Validation

- Full Node suite: 68 passed on final versioned runtime source.
- Browser checks: smoke.test.cjs, attention.browser.test.cjs, search.browser.test.cjs and backup.browser.test.cjs passed. Covers DB migration, duplicate prevention, invalid files, interrupted recovery, simulated quota rollback and compact layouts.
- Packaged Windows assets were tested under matching Electron 42.11.12 using isolated profiles. Native Save produced a valid backup; a clean profile restored a 121-message history copy and displayed it after reload.
- backup.native.test.cjs passed on the final rebuilt package: automatic desktop restore reload, retained synthetic history, native Save and cancellation. Save dialog responses were stubbed to test paths. The desktop reload uses trusted IPC; original storage and the active radio were not used.

## Limitations

Backup files are unencrypted and limited to 50 MB. Existing per-radio history retention remains 3,000 messages; incoming overflow is skipped without deleting existing messages. Restore requires a disconnected radio and does not configure it or transmit messages. Tests use simulations and isolated profiles; no new physical-radio evidence is claimed.
