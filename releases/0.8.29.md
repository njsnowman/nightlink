# Nightlink 0.8.29 stable release preparation

Tracks [#231](https://github.com/njsnowman/nightlink/issues/231) and the [changelog](../CHANGELOG.md#unreleased). Preparation record; publication requires owner approval of the verified artifacts and the physical-radio checks below.

## Scope

The 25 changelog entries after the v0.8.28 release (2026-11-19), delivered as candidates [rc.57](0.8.28-rc.57.md) to [rc.63](0.8.28-rc.63.md) in #225, #228 and #229. Summary:

- Performance: stylesheet `:has()` replaced by state classes, plus the terminal chat append fast path (#207).
- Terminal: status line with node, unread, DM, battery and noise, and docked strip controls (#227); chrome consolidation (top strip hidden, one key bar, More menu, chat bar without repeats); command palette; nick colours; sound packs; F6 split view; custom colours with a contrast guard; page art; pinned messages; update notice off the composer.
- Both interfaces: Nodes LAST SNR with bars, including the final-hop SNR for repeaters; first-run setup guide; Report a bug / Request a feature as a pre-filled GitHub issue.
- LAST SNR from zero-hop adverts (`MeshlineRoutes.parseAdvert`, payload type 4, exact 32-byte key), added after the owner's first check of the release build showed only the owner's own nodes with values. Owner-confirmed rebuild: the radio checks restart on the new build.
- Overview last callers: live refresh and ordering by local heard time (owner report); README rewrite with generated screenshots.
- Fixes: dialog contrast race introduced in rc.57; repeaters showing `-` for LAST SNR; More menu clipping.
- Deferred: channel send confidence (#230, needs a physical RX capture).

Version: `package.json` 0.8.29. `updates.cjs compare` gives 0.8.29 > 0.8.28 > 0.8.28-rc.63, so 0.8.28 installations are offered 0.8.29 and 0.8.29 is not offered 0.8.28. The rc builds sorted below 0.8.28; that is why they were offered 0.8.28.

## Release notes (draft for publication)

```markdown
Stable Windows x64 release of Nightlink.

**Faster chat**
- Received messages render in about 6–8 ms instead of about 110 ms with long histories (simulated, 3,000 messages). Stylesheet `:has()` rules were replaced by state classes, and Terminal chat appends new lines instead of rebuilding. (#207)

**Terminal interface**
- One bottom bar: function keys, page keys and a status line with node, unread, direct messages, battery, noise floor, internet, inbox, update notice and the radio connection. The top strip is gone; Focus and the connection controls moved to the bottom bar. (#227)
- More menu in the menu bar: Contact Book, Mesh Planner, Backup, Propagation, RX Log, Setup guide, Report a bug, Request a feature.
- Ctrl+P command palette to jump to any page, channel, contact or action.
- F6 split view, pinned messages (/pin), nick colours by sender, Modem and BBS bells sound packs, custom colours with a contrast guard, and page title art.
- The update notice no longer covers the message box.

**Both interfaces**
- Nodes: LAST SNR with signal bars, including repeaters (the final hop of received messages), and "5m ago" advert ages.
- First-run setup guide for new installs, linking to the Help topics.
- Report a bug / Request a feature opens a pre-filled GitHub issue. Nothing is sent from Nightlink.

**Validation**
<filled in from this record before publication: CI run, test counts, installer checks, owner physical-radio checks>

**Known limits**
The Windows executables are unsigned. Private queued-message recovery remains unverified. #116 remains open. Channel send confidence ("heard by repeaters") is deferred to #230.

To upgrade, export a Nightlink backup, quit the running app from the tray, and run the Windows installer. Check the downloads against the attached SHA256SUMS.txt.
```
