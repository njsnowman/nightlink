Status: local Windows candidate; no stable release publication or production installation.

## Change

Add Settings > Help & About and a Tools shortcut. Bundle 19 searchable task guides, approximately 3,850 words of Markdown documentation, and eight unique application screenshots. Cover Bluetooth/USB, reconnect/history limits, channel/DM interactions, contact cards/identity, discovery, online/offline maps, adverts/CLI, Radio Health, backups, startup lock, readability/tray behavior, updates and troubleshooting. Guide screenshots use fictional demonstration data in an isolated profile; none depict a physical-radio session.

About reports installed version/distribution mode, local-data and service limitations, project/support links and included Leaflet/QR Code Generator/jsQR notices. Reuse the existing external-link bridge; add no native IPC handlers. Update the update-settings wording to describe the public stable feed and candidate exclusion.
