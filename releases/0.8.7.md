# Nightlink 0.8.7 release record

Tracking: https://github.com/njsnowman/nightlink/issues/11
Status: validation complete; publication pending.

## Scope

Message search from PR #9, tracked in #8: local text search, contact/channel/inclusive local-date/mention filters, keyboard access, offline history and navigation to highlighted messages without marking newer messages read.

## Validation

- Full Node suite: 59 passed on final versioned source.
- Browser checks: smoke.test.cjs, attention.browser.test.cjs and search.browser.test.cjs passed. Radio/notification inputs were simulated.
- Windows package built successfully. Packaged app assets were run under matching Electron 42.11.12 with an isolated history copy: version 0.8.7, 121 messages loaded, 84 rows in the selected channel, 50 initial search results and both filter selectors. A second launch preserved 121 messages and restored the Search view. The test harness redirected only userData and app path; original storage and the active radio connection were not used.
