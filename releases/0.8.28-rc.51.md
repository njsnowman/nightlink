# NightLink 0.8.28-rc.51 local candidate

Tracks [#209](https://github.com/njsnowman/nightlink/issues/209) and the [changelog](../CHANGELOG.md).

Removes the Mesh Planner project report and review shortcut, RF Planning report, full engineering study downloads, comparison field-visit sheet, and simple site note. Full engineering studies display stage results and improvement options in the workspace. The guide and in-app help direct users to the remaining study views and data exports.

## Validation

The unit suite passed 530 tests with one existing skip. Browser checks passed for the full study, site preview, RF Planning, project review and backups, feet and miles, site comparison, CoreScope, and Terminal replies and message paths. The packaged renderer passed CoreScope lifecycle and reaction checks in Terminal and Cards with 3,001 synthetic messages. Physical-radio and installer execution checks remain pending.

In repeated synthetic runs with the same 3,000-message fixture, median redraws ranged from 136 to 370 ms for rc.50 and 158 to 380 ms for rc.51. The timings varied between runs and did not establish a chat speed improvement from removing on-demand reports. Both versions mounted zero hidden Cards message rows and issued zero reaction digest calls for ordinary messages.

The accessibility audit passed 146 screens.
