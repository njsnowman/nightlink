# Nightlink 0.8.28-rc.18 installer design candidate

Tracks [#140](https://github.com/njsnowman/nightlink/issues/140) and [changelog](../CHANGELOG.md). Based on rc.17 main-program functionality; Queen City event changes are excluded.

Replace the amber Switchboard installer identity with the approved Nightlink VGA16 block wordmark, black/blue/cyan artwork, Consolas typography, numbered setup stages and a large wordmark on welcome/finish pages. Update header/sidebar and install-progress colors. Retain native navigation, per-user/no-elevation installation, optional desktop shortcut, retained user data and no automatic app launch.

Artwork is generated by `generate-installer-art.py` from `terminal-logo-art.js`. `installer-assets/ansi-installer-*.png` are design references, not native execution captures. Runtime artwork uses uncompressed RGB24 BMP. Package verification records hashes for installer source and artwork as well as the application payload.

Validation: installer artwork/dimension/palette/layout/policy checks passed 4/4. Full unit suite passed 382 tests, with one existing Python regeneration wrapper skipped. No installation, uninstall, radio connection/configuration/transmission or public publication is part of this work. Owner visual acceptance remains pending; unsigned local candidate.

## Native visual inspection

Opened the built Windows NSIS setup and inspected the welcome, installation-folder and shortcut-options pages. The blue block wordmark rendered, text fit and native navigation remained readable. Cancelled setup before installation. Finish and uninstall pages were not executed; their source/layout and bitmap checks passed. The application itself, detached DM and startup-lock presentation are unchanged from rc.17. No radio testing is claimed for this installer-only change.
