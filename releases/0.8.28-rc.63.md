# NightLink 0.8.28-rc.63 candidate

Owner requests, 2026-11-27: terminal consolidation, update notice placement, first-run guide and feedback. [Changelog](../CHANGELOG.md#unreleased). Previous candidate: [rc.62](0.8.28-rc.62.md). Unpublished candidate for owner evaluation.

## Scope added since rc.62

- Nodes LAST SNR for repeaters, from the final hop of observed routes (owner screenshot report).
- Terminal consolidation (owner chose all four options): the top strip is hidden. Its controls (update notice, Focus, Internet, activity inbox, recovery retry, radio connection) are moved into the bottom status line with their ids and handlers unchanged, and they return to the strip in Cards. There is one key bar; the chat status bar drops the clock, node, link and RF; a More menu sits in the menu bar. The RF indicator is not in the bottom bar (owner request); Propagation is under More.
- Update notice no longer covers the composer: `UPD <version>` in the terminal status line; top right in Cards.
- First-run setup guide (`first-run.js`): only when `meshline.profile` and `nightlink.firstRun` are absent; it never opens automatically under automation. It links to the Help topics Start here, Connect with Bluetooth, Connect with USB, Troubleshooting checklist, Channels & message actions, Add or remove a channel, and Direct messages & alerts.
- Feedback (`feedback.js`): opens a pre-filled `issues/new` URL (2048-character cap, matching the app's link opener) through `nightlinkLinks.open`. Owner choice: GitHub issues; no Discord webhook in the app.
