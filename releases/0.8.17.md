## Behavior
One top-right Connect radio action changes to Connected when linked. Discovery controls precede progress, with no connection dialog scrolling at tested dimensions. Successful synchronization closes the dialog and opens Overview. Failed synchronization keeps error controls visible. Background refresh with the dialog closed does not redirect the workspace. Radio commands and stored history format are unchanged.

## Automated evidence
- Existing unit suite: 114 passed.
- connection-layout.browser.test.cjs: idle/sync/error/ready layout at 760×560, 920×700 and 1320×860; single header action, connected label, automatic Overview entry.
- smoke.test.cjs: simulated GATT synchronization, telemetry, messaging, ACK, retained history and reconnect, including automatic dialog dismissal.
- navigation.browser.test.cjs: 350 contacts / 20 channels, four window sizes and compact modes.
- connection-flow.native.test.cjs: packaged app.asar with matching runtime; Bluetooth/USB simulated synchronization success/error, dialog dismissal and no scrolling.
- tray.native.test.cjs: real Windows tray lifecycle, hide without disconnect, quiet-hour settings, unread IPC, notification routing with mocked native notification, clean Quit.
- Windows NSIS installer and portable builds completed.

## Physical evidence and limitations
No new physical-radio sends, settings changes, firmware writes or microphone recording were performed. COM23 was unavailable during the attempted read-only port-availability check; its current owner was not interrupted. Prior 0.8.16 two-hour USB evidence (#42) is not represented as a 0.8.17 endurance result. Packaged connection state checks are simulated; no transport fix is claimed. Installation into the user's normal profile was not automated.

All acceptance criteria for this UI-only release passed. The broader #43 acceptance criteria remain open and are not part of this release.
