# Nightlink 0.8.28-rc.49 local candidate

Tracks [Terminal reactions #205](https://github.com/njsnowman/nightlink/issues/205) and the [changelog](../CHANGELOG.md).

Terminal chat now uses the same receive-only reaction matcher as Cards. A matched emoji appears beneath the original message. The separate reaction wire message and its hop/delivery row are hidden. Unmatched and out-of-view reactions remain readable with expandable raw details. Retained messages and radio send behavior are unchanged.

- Reactions browser suite: Cards, Terminal and detached DM; matching, raw-details fallback, body alignment, hidden wire/delivery rows, rerendering, out-of-view target and no radio writes passed with synthetic data and blocked external requests.

This is a local candidate, not a published stable release.
