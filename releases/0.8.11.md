# Nightlink 0.8.11 release record

Nightlink 0.8.11 adds Radio Health in Your radio and Settings.

- View Bluetooth uptime, successful reconnections, current synchronization activity and last successful full sync.
- Distinguish completed radio-queue fetch counts from messages in local history. Counts may include duplicates and command responses; interrupted fetches are excluded. An empty radio queue does not prove all missed messages were recovered.
- Inspect errors and existing local-history write failures, with refresh, reconnect and history-export actions.
- Health evidence is session-only. Switching radio resets its sync/fetch evidence; restarting Nightlink resets session metrics. No new radio polling or transport commands are added.

Compatibility

Windows x64. Close Nightlink before installing and back up local data in Settings. Existing %APPDATA%/Meshline storage is retained. Contact storage remains version 2 from 0.8.8; older clients using version 1 may not open upgraded contact cards. Private-repository release discovery remains unavailable anonymously; open GitHub releases while signed in.

Validation

80 Node tests and health browser checks passed. Isolated packaged Windows testing verified panel event updates, local/queue counts, error and reconnect evidence, session reset and saved-history retention with zero radio requests. The existing fake-GATT messaging test passed on rerun after the previously observed intermittent mention-picker assertion failure; no mention fix is claimed. Physical-radio behavior is not validated by these simulations.
