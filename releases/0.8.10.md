# Nightlink 0.8.10 release record

Nightlink 0.8.10 improves message delivery visibility and explicit retries.

- Show queued, sending, retrying, awaiting recipient ACK and final delivery states.
- Add Retry message in main conversations and floating/native DM windows. Confirmation explains that a previous transmission may have arrived without an ACK and retrying can create a duplicate.
- Preserve the original message record when sending again. Block retry while offline or another send is active. No automatic replay on reconnect or restart.
- Label channel broadcasts as accepted by the radio; this does not confirm receipt by another node.

Compatibility

Windows x64. Close Nightlink before installing. Existing %APPDATA%/Meshline storage is retained. Back up local data in Settings before updating. Contact storage remains version 2 from 0.8.8; older clients using version 1 may not open upgraded cards. Private-repository update discovery remains unavailable anonymously; use Open GitHub releases while signed in.

Validation

77 Node tests passed. Delivery browser checks and the fake-GATT messaging integration passed. The latter had one intermittent mention-selection assertion failure before passing on rerun; no mention-behavior fix is claimed. Isolated packaged native testing verified the DM retry IPC, no send before confirmation, acknowledged retry and version 0.8.10 with a simulated radio. No physical radio or two-radio delivery test was performed.
