# Nightlink 0.8.13 release record

Nightlink 0.8.13 adds local backup reminders and clearer save status.

- Weekly in-app reminders with a seven-day snooze and a Settings toggle. Reminders require local data, are suppressed during interrupted-restore recovery and appear at most once per app session.
- Separate confirmed desktop backup saves from browser export starts. Cancelled or failed saves do not record success; later browser exports retain previous confirmed-save evidence.
- Backup creation remains manual. No new radio commands, automatic exports or remote backup are introduced.

Compatibility

Windows x64. Back up local data and close Nightlink before installing. Existing %APPDATA%/Meshline data is retained. Confirmed-save metadata records a completed write, not continued file availability or readability. Backups are unencrypted and should be kept private. Contact storage remains version 2 from 0.8.8; earlier version-1 clients may not open upgraded cards. Private-repository update discovery remains unavailable anonymously; open GitHub releases while signed in.

Validation

87 Node tests, reminder browser checks and existing backup/restore integration passed. Packaged Windows testing saved a real backup file, verified its JSON and restored history, cards and drafts into a separate clean profile. Cancellation recorded no successful save. Save-dialog choices were controlled by the test; native chooser interaction was not exercised. An isolated packaged 0.8.12-to-0.8.13 payload upgrade preserved history, contact notes and existing drafts, with drafts retained after restart. Installer-wizard upgrade and physical-radio testing were not performed.
