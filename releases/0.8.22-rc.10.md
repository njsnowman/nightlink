## Changes

Replace installer header/sidebar artwork with the same geometry, black/ice palette, restrained corner brackets and revised setup copy. Configure installer/uninstaller icons explicitly. Existing per-user installation, optional desktop shortcut, app identity and profile-retention settings remain unchanged.

## Validation

- Independent read-only agent review found no remaining source-level branding/safety or macro conflict.
- ICO directory verified: nine32-bit entries from16 through256pixels with bounded offsets.
- Installer BMPs verified uncompressedRGB24: header450×171, sidebar492×942; downsampled164×314 sidebar preview visually inspected for hierarchy and readability.
- node --test tray.test.cjs: nine passed, including counts/notification lifecycle and quit behavior.
- Isolated built-app.asar validation under matching Electron42.11.12 passed: sidebar logo loaded, nativeImage decoded ICO at256×256, main and native DM window contents rendered. Main-window screenshot inspected. No radio access. A DM screenshot timed out; rendering assertions were rerun without that capture and passed.
- Initial NSIS compile failed due an unsupported Font directive. It was removed in matching source commit 674801a8b9fa836b9898cff547949ad93f12448f; Windows x64 NSIS and portable builds then completed successfully.
- Candidate installer process launched and exposed Nightlink Setup. Windows process metadata confirmed its window handle. The Windows inspection helper incorrectly assigned that handle to GIMP and rejected fresh capture attempts with an ownership mismatch. No wizard input or install action was performed. Only the installer process started by this validation run was closed.

## Unresolved acceptance and scope

**Actual wizard-page visual validation remains blocked by the Windows inspection helper failure.** Welcome, directory, shortcut, progress and finish-page appearance is not asserted. Artwork preview is not equivalent to rendered-wizard evidence. Full install/upgrade/uninstall and multiple-DPI behavior were not tested. These prevent treating this candidate as a validated stable installer. Existing physical backlog acceptance remains open in #49. No stable release/tag published.

Installed application, user profile, radio settings and firmware were not changed. This local preview candidate is provided for review with the above limitations.
