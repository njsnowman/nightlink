# Nightlink 0.8.21-rc.7 — local echo workspace candidate

Tracked in [#51](https://github.com/njsnowman/nightlink/issues/51), [PR #52](https://github.com/njsnowman/nightlink/pull/52). See [changelog](../CHANGELOG.md). Application source: 528b11259ea59149f75595ae9e0edcf6f65edb04.

## Behavior

Selecting the echo channel (with or without a leading #, case insensitive) in Messages opens a 60/40 chat/observer map workspace. The divider supports pointer dragging and keyboard adjustment. Chat/Map/Split controls and Expand map are available. CoreScope starts at latitude 39.44, longitude -85.35, zoom 8 for the Batesville–Cincinnati–Indianapolis area. Incoming render updates retain the existing iframe rather than restarting its feed. Selecting another channel or leaving Messages removes the echo iframe and restores normal panel ownership.

Offline or explicit Local map switches to the existing local radio map and downloaded street tiles where coverage is installed; online restoration reloads CoreScope. Missing offline coverage retains the existing coverage notice. Observer activity is explicitly separate from message delivery acknowledgment. There is no packet-to-command correlation or promise that a particular command is observed.
