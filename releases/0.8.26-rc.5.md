# Nightlink 0.8.26-rc.5 - Remote administration timing candidate

Tracking: [#109](https://github.com/njsnowman/nightlink/issues/109); implementation [PR #110](https://github.com/njsnowman/nightlink/pull/110).

Remote CLI commands now read the companion RTC and use strictly increasing timestamps, paced before transmission so bursts do not run ahead of that clock. This avoids PC clock skew and repeated whole-second timestamps on older companions. No radio clock is written. Remote reply budgets begin after companion acceptance and honor its path estimate plus a margin, bounded at 180 seconds. Matching replies that arrive during transport acceptance remain valid. Writes are never retried automatically.

Inspect settings now shows the current field, completed count and total number of mesh round trips. An interrupted inspection names the failing field and does not create an editable snapshot.

## Physical evidence before the fix

- Connected companion reports protocol 13. A read-only `/clock` query matched PC time at observation.
- After clearing an earlier timed-out session through a companion reconnect, the named repeater returned administrator login success.
- Inspect settings then timed out awaiting a CLI reply. The previous UI did not identify which field stalled, so a specific dropped field or replay rejection was not physically proven.
- No radio configuration or password changes were sent. Credentials are omitted from all records.
- A diagnostic relaunch with a local debugging port was blocked by automatic approval review. Nightlink was restored normally; this candidate does not expose a debugging port.

## Validation

Regression tests cover RTC/PC skew, unique paced timestamps, bounded estimated deadlines, replies during delayed acceptance, refusal to transmit without a valid companion clock, and per-setting progress/failure context. Final suite and packaged evidence follow below. Physical full inspection on this candidate remains pending installation; do not claim physical resolution from synthetic tests alone. This is a candidate, not a stable release.
