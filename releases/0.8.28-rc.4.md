# Nightlink 0.8.28-rc.4 diagnostic candidate

Issue: [#131](https://github.com/njsnowman/nightlink/issues/131). PR: [#132](https://github.com/njsnowman/nightlink/pull/132). Previous candidate: [rc.3](0.8.28-rc.3.md). [Changelog](../CHANGELOG.md).

## Scope

Owner request on 2026-11-03: fine-tune the terminal graphics toward a more authentic BBS look, for MRC chat, window and dialog bars, and the ANSI maps. Presentation only; no radio, storage or send-path changes.

- MRC: stable per-nick colors (eight VGA colors, each 4.5:1 or better on black); `***` banner lines on each window (window name, topic, stored-message and node counts from local data); yellow day-change lines; `[ WINDOWS ]` / `[ NODES ]` headers over a double rule; `►` marker on the active window (CSS only, not part of the accessible name); double rules between panes.
- Dialog windows: `[■]` close control on the left of the blue title bar (accessible name unchanged), solid dark-grey drop shadow, dithered blue backdrop; decorative line icon hidden in terminal titles; section headings in yellow.
- Buttons in dialog and page windows: flat grey, cyan (primary) or red (destructive) blocks with a dark-grey shadow that disappears while pressed. Buttons that contain card content keep their layout.
- ANSI path view and node map: box-drawing frame with `N ▲`, distance scale from the plotted bounds (great-circle width at the middle latitude), wider grids (96 x 14 and 110 x 18), and known segments drawn with `─ │ ╱ ╲` chosen per step.
