# Nightlink 0.8.26-rc.3 - Device Center layout candidate

Tracking: [#109](https://github.com/njsnowman/nightlink/issues/109); implementation [PR #110](https://github.com/njsnowman/nightlink/pull/110).

Device Center now uses filled primary actions, bordered secondary buttons, distinct disabled/hover/focus states, a connection card, grouped identity/radio/routing/advert settings and compact responsive spacing. The file selector and review controls have matching visible surfaces. Radio command behavior is unchanged from rc.2.

Validation: Device Center rendered checks pass at 1440, 1024 and 760 px, including compact layout and 130% reading scale. Existing-feature browser and package verification are recorded after the build below. Physical-radio acceptance remains open as documented for rc.2; no hardware configuration was changed. This is a local candidate, not a stable release.
